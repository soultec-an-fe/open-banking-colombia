# 13 · Glosario de siglas y entidades

**Fecha de corte: 10 de septiembre de 2026**

---

## Reino Unido

| Sigla | Significado | Qué es |
|---|---|---|
| **OBIE** | *Open Banking Implementation Entity* | Organismo creado por la **CMA** en 2016–2017 para implementar el mandato de open banking. Escribió el Open Banking Standard, operó el directorio, certificó conformidad y publicó métricas. Financiado por los CMA9. **En 2021 se reorganizó como OBL** |
| **OBL** | *Open Banking Limited* | Sucesor de OBIE. Mantiene el estándar y el directorio hoy. Candidato a convertirse en la Future Entity |
| **Future Entity** | — | Organismo permanente de estándares que la FCA está constituyendo para reemplazar a OBL. Diseño consultado en FS25/4. Sin ánimo de lucro, *company limited by guarantee*. Candidatos: OBL y Smart Data Group |
| **CMA** | *Competition and Markets Authority* | Autoridad de competencia. Emitió el **Retail Banking Market Investigation Order 2017**, la base legal original del open banking británico |
| **CMA9** | — | Los nueve bancos obligados por el CMA Order: Barclays, HSBC, Lloyds, Nationwide, NatWest, Santander, Danske, Bank of Ireland y AIB |
| **FCA** | *Financial Conduct Authority* | Regulador de conducta. Hoy lidera la transición a open finance y su roadmap a 2030 |
| **PSR** | *Payment Systems Regulator* | Regulador de sistemas de pago (⚠️ no confundir con el *Payment Services Regulation* de la UE) |
| **JROC** | *Joint Regulatory Oversight Committee* | Comité creado en 2022: FCA, PSR, HM Treasury y CMA. Definió las recomendaciones sobre modelo comercial y Future Entity |
| **UKPI** | *UK Payments Initiative* | Esquema industrial de **cVRP** lanzado en junio de 2026, con 31 firmas |
| **VRP / cVRP** | *Variable Recurring Payments* / *commercial VRP* | Mandato que autoriza pagos recurrentes de monto variable dentro de límites. *Sweeping* (entre cuentas propias) es obligatorio; el comercial va por esquema voluntario |
| **DUAA** | *Data (Use and Access) Act 2025* | Ley que habilita *smart data schemes* en cualquier sector. Royal Assent el 19-jun-2025 |
| **PRISM** | *Prioritisation and Real-world Insights Selection Matrix* | Taskforce de la FCA para priorizar casos de uso de open finance |
| **ASPSP** | *Account Servicing Payment Service Provider* | El banco que tiene la cuenta. Equivale al **Proveedor de Datos** colombiano |
| **TPP** | *Third Party Provider* | Tercero. Se divide en AISP y PISP |
| **AISP / PISP** | *Account Information / Payment Initiation Service Provider* | Lectura de datos / iniciación de pagos |
| **PSU** | *Payment Service User* | El cliente. Equivale al **Titular** colombiano |
| **CASS** | *Current Account Switch Service* | Servicio de portabilidad de cuentas corrientes (previo y separado del open banking) |
| **OBWAC / OBSeal** | *Open Banking Website Authentication Certificate / Seal* | Certificados de la PKI de open banking británica |

## Unión Europea

| Sigla | Significado | Qué es |
|---|---|---|
| **PSD2 / PSD3** | *Payment Services Directive* 2 y 3 | Directiva de servicios de pago. PSD2 vigente desde 2018; PSD3 acordada en trílogo en abril de 2026 |
| **PSR** | *Payment Services Regulation* | Reglamento que acompaña a PSD3, directamente aplicable (⚠️ no confundir con el regulador británico) |
| **FIDA** | *Framework for Financial Data Access* | Propuesta de reglamento de open finance europeo. **En trílogo, detenido desde inicios de 2026** |
| **FISP** | *Financial Information Service Provider* | Nueva figura de tercero que crearía FIDA |
| **FDSS** | *Financial Data Sharing Scheme* | Esquemas de gobernanza obligatorios de FIDA, donde se acuerda la **compensación económica** |
| **SCA** | *Strong Customer Authentication* | Autenticación reforzada: dos de tres factores + *dynamic linking* |
| **RTS** | *Regulatory Technical Standards* | Normas técnicas. El **RTS on SCA & CSC** es el Reglamento Delegado (UE) 2018/389 |
| **EBA** | *European Banking Authority* | Autoridad bancaria europea |
| **eIDAS** | *electronic IDentification, Authentication and trust Services* | Marco de identidad digital. **eIDAS 2** crea la EUDI Wallet |
| **QWAC / QSeal** | *Qualified Website Authentication Certificate / Qualified Seal* | Certificados cualificados bajo eIDAS |
| **Berlin Group** | — | Iniciativa de estandarización. Su **NextGenPSD2** evolucionó al **openFinance API Framework** |
| **STET** | — | Estándar de API francés |

## Estados Unidos

| Sigla | Significado | Qué es |
|---|---|---|
| **CFPB** | *Consumer Financial Protection Bureau* | Regulador que expidió la regla §1033 |
| **§1033** | Sección 1033 de la Dodd-Frank Act | Base legal del derecho de acceso a datos financieros del consumidor |
| **FDX** | *Financial Data Exchange* | Consorcio de industria que publica la FDX API. **Reconocido por el CFPB como organismo de estandarización en enero de 2025** |
| **ANPR / NPRM** | *Advance Notice of Proposed Rulemaking* / *Notice of Proposed Rulemaking* | Etapas del proceso reglamentario. ANPR de ago-2025; NPRM enviado a OIRA en ago-2026 |
| **OIRA** | *Office of Information and Regulatory Affairs* | Oficina que revisa reglamentos bajo la Orden Ejecutiva 12866 |
| **GLBA** | *Gramm-Leach-Bliley Act* | Ley de privacidad financiera de 1999. La **GUARD Act** la modernizaría |
| **Regulation E** | — | Reglamento de transferencias electrónicas de fondos. Delimita el alcance de la regla §1033 |
| **NYDFS** | *New York Department of Financial Services* | Regulador que aplicaría el "mini-1033" neoyorquino |
| **UDAP** | *Unfair or Deceptive Acts or Practices* | Autoridad de los fiscales generales estatales |

## Brasil

| Sigla | Significado | Qué es |
|---|---|---|
| **BCB** | *Banco Central do Brasil* | Regulador y orquestador del Open Finance Brasil |
| **JSR** | *Jornada Sem Redirecionamento* | Flujo que permite autorizar un pago sin salir de la app del iniciador. Liberación general el 22-abr-2026 |
| **Pix** | — | Sistema de pagos instantáneos del BCB, integrado con la iniciación de pagos |
| **ICP-Brasil** | *Infraestrutura de Chaves Públicas Brasileira* | PKI nacional usada para autenticación mutua entre instituciones |
| **ANPD** | *Autoridade Nacional de Proteção de Dados* | Autoridad de protección de datos |

## Colombia

| Sigla | Significado | Qué es |
|---|---|---|
| **SFC** | Superintendencia Financiera de Colombia | Supervisor. En finanzas abiertas es además **fijador de estándares y administrador del directorio** |
| **SIC** | Superintendencia de Industria y Comercio | Protección de datos personales (Ley 1581) y abogacía de la competencia (art. 7 Ley 1340 de 2009) |
| **URF** | Unidad de Proyección Normativa y Estudios de Regulación Financiera | Unidad del MinHacienda que **proyecta** los decretos financieros. Aprobó el D-0368 en Acta 22 del 19-dic-2025 |
| **CBJ / CBF** | Circular Básica Jurídica / Financiera | Compilaciones de instrucciones de la SFC. El **Capítulo IX del Título I de la Parte I de la CBJ** contiene las reglas de finanzas abiertas |
| **CE / CC** | Circular Externa / Carta Circular | Instrumentos normativos de la SFC. La **CE** es vinculante; la **CC** informa o comunica |
| **PND** | Plan Nacional de Desarrollo | La **Ley 2294 de 2023** (PND 2022–2026) es la habilitante legal: arts. 88 lit. e), 89, 94, 97 y 104 |
| **EOSF** | Estatuto Orgánico del Sistema Financiero | **Decreto 663 de 1993** |
| **SEDPE** | Sociedad Especializada en Depósitos y Pagos Electrónicos | Licencia obligada como Proveedor de Datos (art. 2.35.8.2.3) |
| **IOE** | Institución Oficial Especial | Obligadas si fueron definidas como establecimiento de crédito en su acto de creación |
| **SARLAFT** | Sistema de Administración del Riesgo de Lavado de Activos y Financiación del Terrorismo | Debida diligencia aplicable a la vinculación de Terceros Receptores No Vigilados |
| **RNBD** | Registro Nacional de Bases de Datos | Decreto 886 de 2014. Requisito para no vigilados cuando aplique |
| **SCI** | Sistema de Control Interno | Debe albergar el área responsable de las pruebas de calidad de datos |
| **Bre-B** | — | Sistema de pagos inmediatos interoperable del Banco de la República |
| **TRD** | Tercero Receptor de Datos | Abreviatura usada en esta documentación. Puede ser **Vigilado** o **No Vigilado** |

## Estándares técnicos

| Sigla | Significado |
|---|---|
| **FAPI** | *Financial-grade API* — perfil de seguridad de la **OIDF** |
| **OIDF** | *OpenID Foundation* |
| **OIDC** | *OpenID Connect* — capa de identidad sobre OAuth 2.0 |
| **PAR** | *Pushed Authorization Requests* (RFC 9126) — obligatorio en FAPI 2.0 |
| **PKCE** | *Proof Key for Code Exchange* (RFC 7636) — obligatorio con S256 |
| **DPoP** | *Demonstrating Proof-of-Possession* (RFC 9449) — vinculación de token al remitente |
| **mTLS** | *mutual TLS* (RFC 8705) — autenticación mutua y tokens vinculados a certificado |
| **JAR / JARM** | *JWT-Secured Authorization Request / Response Mode* — piezas de FAPI 1.0 que FAPI 2.0 sustituye |
| **CIBA** | *Client-Initiated Backchannel Authentication* — flujo desacoplado; base conceptual de la JSR brasileña |
| **JWT / JWS / JWK** | *JSON Web Token / Signature / Key* |
| **PS256** | RSASSA-PSS con SHA-256 — algoritmo de firma exigido por la SFC (o superior) |
| **ISO 20022** | Estándar de mensajería financiera. Diccionario de datos exigido en Colombia |
| **ACORD** | Estándar de datos para la industria de **seguros** |
| **ISIN / CFI / FIX / OpenFunds** | Estándares de identificación y mensajería para **inversión** |
| **OpenAPI** | Especificación de descripción de APIs REST. Colombia exige la **versión 3.1** |
| **OWASP API Top 10 / ASVS** | Marcos de seguridad de aplicaciones y APIs |
| **NIST SP 800-204** | Guía del NIST sobre seguridad de microservicios y APIs |
| **CSA** | *Cloud Security Alliance* |
| **DAMA** | *Data Management Association* — criterios de calidad de datos exigidos por la SFC |
| **PCI-DSS / QSA / AoC** | Estándar de seguridad de datos de tarjetas / auditor cualificado / atestación de cumplimiento |
